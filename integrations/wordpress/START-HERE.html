אתר לפורטפוליו + גרסת ניסיון ל־WooCommerce

האתר הציבורי שלך

אפשר כבר להציג ולשתף את האתר הקיים של MOVA. הוא כולל את הקטלוג, סיבובי המוצרים והפתיחה הקולנועית. תהליך הקנייה בו הוא הדגמה.

הפרסום ב־Vercel עדיין לא בוצע: החיבור לחשבון החזיר שגיאת הרשאה 403 בעת יצירת הפרויקט. צריך לחדש את החיבור עם גישה לצוות הנכון, ואז אפשר לפרסם את החבילה המוכנה.

לנסות WooCommerce

  1. חלצו את החבילה למחשב. בתוך WordPress, היכנסו לעיצוב ← תבניות ← הוספת תבנית ← העלאה.
  2. בחרו את הקובץ mova-motion-woocommerce.zip, התקינו והפעילו MOVA Motion באתר ניסיון.
  3. הפעילו WooCommerce והשלימו את ההגדרות שלו. התבנית משתמשת בעגלה ובקופה של WooCommerce.
  4. בעיצוב ← MOVA Motion אפשר לייבא 12 מוצרי הדגמה. הם יישמרו כטיוטות עם מידות, צבעים, מלאי ורכיבים. פרסמו את הטיוטות הרצויות רק בחנות הניסיון.
  5. בעריכת כל מוצר, בלשונית MOVA 360°, אפשר להוסיף אטלס של זוויות מוצר ופירוט רכיבים. תמונה אחת רגילה אינה מספיקה כדי לראות את המוצר מכל הצדדים.

בעמודי המוצר: גרירה לסיבוב, צביטה בשתי אצבעות לזום עד פי 12, ופירוט רכיבים בלשונית נפרדת. סל, וריאציות, מלאי והזמנות מנוהלים ב־WooCommerce.

זו תבנית ניסיון ראשונה. מוצרי הקונספט אינם מוצרים אמיתיים למכירה, והזוויות שנוצרו ב־AI עשויות להשתנות מעט בין פריימים. יש לבצע בדיקה בדפדפן ובטלפון ובסביבת התשלום המיועדת לפני שימוש בחנות מסחרית.

חבילת Vercel

mova-vercel-portfolio.zip מכיל את האתר הסטטי ואת הגדרות הפריסה. חלצו אותו והשתמשו בתיקייה כשורש הפרויקט: Framework = Other, Output Directory = dist, ללא פקודת build. מתוך התיקייה אפשר לפרסם באמצעות vercel --prod אחרי התחברות לחשבון הנכון. החבילה אינה כוללת פרטי תשלום או סודות.

לפרטים הטכניים: README.md בתוך תבנית WordPress. תוצאות הבדיקות נמצאות ב־VALIDATION.md.
